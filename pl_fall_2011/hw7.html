The semifactorial of a positive integer n is 1 × 3 × 5 × ... × n if n is odd and 2 × 4 × 6 × ... × n if n is even. Use the reduce function to define a semifac function which calculates semifactorials.

This function works by transforming the numbers from 1 to n/2 into either 2*x if the original input was even or 2*x+1 if the original input was odd. All of the transformed numbers are multiplied together, yielding a semifactorial.

Which, if either, of the following are well defined?
  1. compose (compose, uncurry compose)
  2. compose (uncurry compose, compose)

In the context of a statically typed functional language "well defined" means roughly "will survive parsing and type checking." The second expression is definitely not well defined. If you look at the types of 'uncurry compose' and 'compose' you'll see that they can't be plugged together. The first expression is more complex: it's technically well defined but causes the type checker to emit an error. This happens for reasons way beyond the scope of our class. If you're curious, you can read about ML's value restriction.

I think this question is confusingly worded. You can't define short-circuiting logical operators from within SML. Eager evaluation won't let you! What you can do is define logical operators which fully evaluate both their arguments before computing a result. These are just conjunction and disjunction functions from the first question.
