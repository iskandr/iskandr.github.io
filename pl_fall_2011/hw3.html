Homework 3 Solution

You had a lot of flexibility in the details of this homework, so any two solutions might differ considerably. A correct solution should satisfy the following criteria:
  • A polynomial datatype implemented using a singly-linked list of terms (or some other collection whose elements you dynamically allocate).
  • Correct implementations of "+", "*", and "=" operators.
  • A main procedure (located outside your Polynomials package) which loads and evaluates multiple test cases.
  • Test cases can be in whatever format you choose, but you should perform some basic error checking to detect malformed input.
  • As always, clear and purposeful comments throughout your code.
